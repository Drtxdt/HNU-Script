## 检查范围

- Rust 原有 SQLite、SQL 语义、关系代数、事务、工程、精确数值回归，加上动画专测：TRUE/FALSE/UNKNOWN、重复行实例、JOIN 分支／候选、NULL 与 NOCASE 分组、空集聚合、COUNT 累计、HAVING、除法与空除数、回滚原值和隐藏数据保护。
- 前端 Vitest（12 项）：暂停／恢复、调速、随机跳转、10,000 事件的完整计数与合批、等待环只突出环上的边。ESLint、vue-tsc、Clippy -D warnings 与发布构建。
- 官方 tauri-driver + EdgeDriver 驱动真实 Tauri EXE。播放中暂停分数进度不变、图节点坐标不变、减少动态效果移除流动连线、逐事件跳转、专注视图、公开练习入口、编辑后取消旧视图。额外对真实 IPC 返回施加 700 ms 延迟，验证切题和取消拒绝已经计算完成的旧结果。
- 10,000 行原生 SQLite 中间表实际生成并回放，默认两操作合计 42 个演示事件；完整行数保留。当前视图 35 条实体数据行加一个虚拟占位行，最多两个移动副本。
- JOIN、筛选聚合、代数优化、事务死锁短演示采用真实 WebView2 截图按采样时间戳合成；WebView2 页面 screencast 使用真实时间戳，交付 MP4 编码为 30 fps；额外 PNG 关键帧约 6–8 fps，不将它们视为渲染帧率。
- rAF 间隔单独采集，本机前轮中位约 4.2 ms、P95 约 4.3 ms；这不是 GPU 帧耗时或跨设备 60 FPS 保证。最终逐场景测量见 acceptance 的 JSON。
- 独立 MySQL 9.5 实例仅监听 127.0.0.1:13367，使用 build/qa/mysql-data；例程、多结果集、只读过程、真实锁等待、死锁和回滚回归通过。未修改原 MySQL95 服务。
