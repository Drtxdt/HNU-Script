# 1.1 动画与高亮

## 使用

1. 在查询工作台点“生成查询过程”，或在代数页点“运行并优化”、事务页点“模拟并判定”。练习的“逐步演示”只使用公开数据。
2. 点播放。每事件逻辑时长 1 秒：定位、处理、落位、核对。主要位移约 400 ms，速度支持 0.5/1/2/4 倍；暂停保留事件内的小数进度。
3. 上／下一步、滑块、图节点都直接恢复冻结状态，不重跑查询。点击输入或输出记录暂停查看关联，再播放退出查看状态。
4. 宽面板并排显示输入和输出；窄面板堆叠。专注演示更适合课堂投屏。完整表虚拟滚动，每表最多约 35 个实体数据行，移动副本最多两个。
5. 工程保存详细程度和减少动态效果偏好。旧工程自动采用默认值；派生事件重新生成。减少动态效果取消连续位移和连线流光，但保留当前状态。

## 语义

- 记录标识为冻结表 ID + 行实例位置，同值重复行仍是不同实例。
- WHERE/HAVING 的 TRUE/FALSE/UNKNOWN 由同一数据库快照中的 CASE 探针计算；不在前端模拟 SQL 真值。
- JOIN 显示两侧输入。完整拼接结果唯一确定两侧实例时标记已验证，未匹配侧补 NULL；重复来源或全 NULL 歧义标记候选，虚线表示不确定。每侧最多高亮 24 个候选，不声称物理行来源。
- SQL 分组成员使用数据库生成的分组编号；简单 COUNT/SUM/AVG/MIN/MAX 使用数据库窗口探针显示累计值。COUNT(*) 包含 NULL 行，COUNT(列) 忽略 NULL。DISTINCT 聚合及复合聚合表达式仍展示冻结结果，不伪造累计值。累计窗口的枚举次序是教学快照次序，不代表引擎实际物理顺序。
- 去重／排序／分页按冻结行对应回放；未声明的排序并列顺序没有唯一性保证。集合与多重集语义沿用原操作。
- 除法逐个候选检查除数要求，探针使用原生 NULL 安全比较；空除数条件为真。
- 事务数据值直接显示原值与新值，不做数值插值。优先图与等待图先布局，再按事件显隐边；锁、释放、局部变量与版本来自模拟器冻结记录。
- 真实 MySQL 只回放已记录请求及返回；正在等待响应不等于已观测到服务器锁等待，不推测内部锁事件。
- 练习差异高亮按行多重集（排序题按位置）标记，不暴露隐藏测试答案。

## 已知范围

来源不确定时仍可看最终冻结结果，但不会画成唯一匹配。相关子查询显示外层记录与原生子查询返回值，目前不展开每次相关求值的完整内层表。复杂表达式的逐单元格数据依赖、分组聚合中的最终组到输出行绑定仍可能只有候选／结果级说明。优化对照显示规则和前后中间行数，不把图形位置移动当作优化算法。

源范围优先采用 AST 保留的位置，再转换为 UTF-16；重复 WHERE／UNION 分支和中文、emoji 有专测。解析器不保留位置的运算使用 token 回退定位。课程源位置说明与完整 SQL 可在步骤下展开。

图导出冻结当前高亮，移除移动连线残影；导出的是图本身。动画抽样只影响播放时长，不改变查询或判题结果。

## 自检

`pnpm test` 检查时钟暂停、调速、随机跳转与 10,000 事件合批。`cargo test -p sql-killer-core --test animation` 检查数据库真值、重复实例、JOIN、NULL 分组、COUNT、HAVING、空集聚合、除法和回滚。

真实桌面录帧：设置 `SQL_KILLER_QA_MOTION=1`、`SQL_KILLER_QA_LABEL=motion`、`SQL_KILLER_TEST_EXE` 后运行 `node tools/e2e.mjs`。设置 SQL_KILLER_QA_FFMPEG 为本机 ffmpeg 路径可从验收专用 WebView2 获取 screencast 帧，按时间戳编码 MP4。SQL_KILLER_QA_RACES=1 额外验证延迟返回不会覆盖新题目或已取消的任务。录屏采样率与 rAF 帧间隔测量分开，不把录屏帧数当渲染 FPS。
