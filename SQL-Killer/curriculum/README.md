`student.sql` 中 Student 的 5 行、Course 的 7 行、SC 的 6 行对应复杂关系代数 p.21，按外键依赖调整插入顺序。Department、Teacher 为教学补充。NULL、重复姓名、新增系和空表数据仅注入隔离判题数据组，不改变公开课堂主数据。

Hotel 表结构参考关系模型 p.51–52，具体样例值为补充。Bank 为事务实验专用补充数据。Empty Sandbox 不含预设表。

方言说明：课件综合多种数据库语法。SQLite 不实现存储过程／自定义 SQL 函数，例程题使用 MySQL；触发器题在题目上标明 SQLite，采用 `AFTER UPDATE OF … BEGIN … END`。MySQL 普通快照读与课本共享锁模型不同，真实双会话遵循服务器返回。

补充内容：固定运行时离线部署、工程恢复、CSV／JSON、非递归 CTE、现代 SQLite 外连接、精确数值传输、固定种子与多数据判题、资源限制，均为工具工程功能，不作为课件原文。

随机种子改变年龄筛选题阈值，答案与进度以 `题目ID@种子` 保存。其余固定题保留原语义，避免随机化改变教学目标。隐藏数据覆盖 NULL、重复值、无匹配、空关系；不会承诺证明所有可能数据库上的 SQL 等价。
