# SQL-Killer 1.0.0 验收记录

记录日期：2026-09-30。当前电脑 Windows 11 25H2，内部版本 26200.9457，x64；注册表 ProductName 仍显示 Windows 10 Home China，按实际构建号识别。Windows 10 22H2 与其他 Windows 11 版本未实测。

## 已完成的核心验证

- SQLite 原生执行、外键、ATTACH 限制、脚本字符串／注释／触发器分割、撤销事务、精确整数及结果上限。
- 20 个查询覆盖外连接 ON／WHERE、自然连接、GROUP BY／HAVING、空集聚合、COUNT、去重、NOT IN、相关子查询、CTE、集合运算、排序分页和多表连接；过程与原查询同快照一致。
- 窗口函数、随机函数、副作用语句被明确排除出过程视图，没有生成伪造的完整结果。
- SQLite 活动事务的一致性副本保留未提交值且不提交原事务；取消／超时不返回完整结论。
- 所有 SQLite 参考答案经过三组数据与行为探针；错误 NULL 条件、扩大修改范围被拒绝。结构判题比较对象类型、列、默认值、外键、索引列及数据，触发器使用真实更新探针。
- 关系代数集合语义、空除数、重命名、属性域不兼容、优化一致性；随机生成含重复值和 NULL 的关系与独立 SQL 对照。
- 事务模拟验证脏读、级联、丢失修改、死锁、排队后表达式求值、范围记录移出谓词时的锁保护；盲写案例区分冲突与视图等价。
- UTF-8 字节位置转 Monaco UTF-16（包含中文和 emoji）；Decimal 超过 28 位仍进行精确十进制比较。
- 工程往返、密码剔除、损坏文件、未知格式版本；前端修订号和任务 ID 防止旧结果回填。

## MySQL 独立实例

使用本机 MySQL 9.5.0 二进制，单独初始化 `build/qa/mysql-data`，仅监听 127.0.0.1:13367。未操作原 MySQL95 服务或其数据目录。

实际验证：整数／Decimal 传输、只读分组过程、双会话未提交隔离、真实锁等待后回滚释放、InnoDB 1213 死锁、多结果集 CALL、存储过程／函数三组数据判题及副作用。Student 的两个 SC 外键在 MySQL 中真实存在，非法外键插入被拒绝；种子导入将 SQLite 的列级引用转换成 MySQL 表级外键。判题每次创建并清理独立库与临时低权限用户，不修改全局配置。

## 真实桌面

官方 tauri-driver 2.1.0 + EdgeDriver 154.0.4258.48 驱动原生 Tauri 程序。首轮和扩展流程通过，截图与 WebDriver 日志保存在 `build/qa`。键鼠操作覆盖 SQL 执行、查询过程、代数、事务模拟、课程参考答案判题与中文 SQL 输入。工程中文／空格路径、emoji 文档和 CSV 导出另外通过真实 IPC 验证。

## 明确边界

- 逻辑过程不是物理执行追踪；行来源视图按保留字段展示候选来源，值相同的重复记录不伪称具有唯一物理身份。
- 容错补全与课程绑定诊断是教学语言服务，最终语法与类型合法性由实际数据库判定。
- 非递归 CTE 可以执行和可视化；编辑器对显式 CTE 列列表、星号派生列的补全仍不完整。MySQL 会话历史当前仅在事务页面存续期间回放，不作为工程持久化内容。
- 视图可串行化枚举针对不含回滚的点读写调度；范围／回滚或资源上限显示未完成，绝不判成错误答案。范围模拟仍记录锁和谓词冲突。
- 独立代数至少保留一个输出属性；空关系的动态属性类型不能从实际值推断。随机变体目前改变年龄筛选阈值，其余题固定。
- 图形导出仅导出图本身；报告含冻结输入、表格、步骤、结论和课程来源。CSV 将 NULL 显示为文字，类型无损数据请使用 JSON。
- 不声称一般 SQL 等价已获证明；测试通过仅针对记录的测试数据。未签名安装包可能出现 Windows SmartScreen 提示。
